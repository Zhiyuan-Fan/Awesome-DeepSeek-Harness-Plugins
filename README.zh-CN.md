# Awesome DeepSeek Harness Plugins

[English](README.md) | [简体中文](README.zh-CN.md)

一个每日维护的 [DeepSeek Harness](https://www.deepseek.com/harness/)（DSH）公开插件与扩展精选目录，涵盖工具、技能、模型提供商、记忆、自动化、运行时、桌面客户端、浏览器集成与开发者工具。

每个条目均提供规范 GitHub 仓库、当前 Stars 与独立验证的引用网页。

> 收录标准：公开、实用、持续维护，并且明确面向 DSH。安装前请自行检查插件代码与权限。
